NoticeBoard — Доска объявлений с рассылкой новостей
Проект на Django, предоставляющий функциональность создания, редактирования и отклика на объявления, а также систему email-рассылок, регистрацию через код-подтверждение и загрузку медиафайлов (изображения/видео).

Возможности:

- Регистрация через email с подтверждением кода.
- Авторизация пользователей.
- Роли пользователей (пользователи и маркетологи).
- Создание/редактирование/удаление объявлений.
- Создание текста, который может содержать изображения, встроенные видеоролики ссылки и emoticons, осуществляется с помощью редактора TinyMCE.
- Отклики на объявления и управление ими.
- Приватная страница со своими объявлениями и откликами.
- Массовая email-рассылка зарегистрированным пользователям (только для маркетологов).
- Темная тема интерфейса с использованием Bootstrap 5 (Bootswatch Slate).
- Пагинация, фильтрация по категориям.

Используемые технологии:

- Python
- Django
- Celery + Redis 
- Bootstrap 5 (Bootswatch Slate)
- TinyMCE (WYSIWYG-редактор)
- Yandex SMTP (для отправки писем)
- SQLite

Роли пользователей:

Пользователь — может размещать объявления, просматривать отклики.
Маркетолог — член группы Маркетологи, может создавать и отправлять рассылки.
Маркетолог может создавать рассылки, которые автоматически отправляются всем зарегистрированным пользователям с помощью Celery.

Создание рассылки
- Добавте пользователя в группу "Маркетологи"
- Перейдите на страницу создания рассылки
- После создания она автоматически отправится всем зарегистрированным пользователям

Безопасность:

- Все формы защищены CSRF.
- Только автор может редактировать/удалять свои объявления.
- Проверка прав осуществляется через миксины (LoginRequiredMixin, OwnerRequiredMixin).
